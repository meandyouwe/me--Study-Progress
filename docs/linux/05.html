5. 时间编程

嵌入式与系统编程里的「时间」有三层含义：日历时间（人类可读）、时间戳（秒数）、单调时间（只增不减的计数器）。混用会写出「系统改时间后定时器错乱」这类隐蔽 bug。

（二）time：取日历时间

返回自 1970-01-01 00:00:00 UTC 起经过的秒数（Unix 时间戳）。参数可为 NULL，也可传入地址由函数回填。两种写法等价：

time_t 在 32 位系统上是 32 位有符号整数，最大到 2038-01-19 03:14:07，这就是「2038 问题」。现代 64 位 Linux 已改为 64 位。

（三）struct tm 与转换函数

函数原型作用
localtimestruct tm *localtime(const time_t *)秒数 → 本地时间
gmtimestruct tm *gmtime(const time_t *)秒数 → UTC（比北京时间慢 8 小时）
ctimechar *ctime(const time_t *)秒数 → 固定格式字符串
asctimechar *asctime(const struct tm *)结构体 → 固定格式字符串
strftimesize_t strftime(char *, size_t, const char *, const struct tm *)结构体 → 自定义格式
mktimetime_t mktime(struct tm *)本地时间结构体 → 秒数（逆向）

符含义示例

%m两位月11
%d两位日25
%H %M %S时 分 秒19 20 44
%F等价 %Y-%m-%d2026-11-25
%T等价 %H:%M:%S19:20:44

易错点：strftime 返回 0 有两种可能——格式化结果为空串，或缓冲区不足。判断失败要看 errno，不能只看返回值。

（六）延时与计时

函数精度可被信号中断说明
sleep(n)秒是，返回剩余秒数最常用
usleep(us)微秒是已废弃
nanosleep(&req, &rem)纳秒是，rem 给出剩余推荐，精度最高
clock_gettime(CLOCK_MONOTONIC, &ts)纳秒否测耗时必须用它

扩展 · 为什么测耗时不能用 time()：time() 的分辨率是 1 秒，且会被系统对时（NTP）向前或向后调整。CLOCK_MONOTONIC 从开机起单调递增，不受改时间影响，是测量时间间隔的唯一正确选择。
