# C 语言知识库 · 知识总结与易错点复盘

一份按课程顺序整理的 C 语言学习笔记，12 章主干 + 47 个小节，覆盖从编译流程、类型与指针，到结构体对齐、动态内存与文件操作的常见考点与易错点。

同一份内容有三种形态：**网页版**（在线浏览 / 全文搜索 / 亮暗模式）、**Word 版**（可编辑、可打印、留了个人复盘区）、**Markdown 源文件**（唯一内容源，改动后两端可重新生成）。

## 内容概览

| 章节 | 主题 | 章节 | 主题 |
|---|---|---|---|
| 一 | 程序结构与编译执行流程 | 七 | 指针 |
| 二 | 数据类型与变量（含内存分区） | 八 | 结构体、共用体、枚举与 typedef |
| 三 | 运算符与表达式 | 九 | 动态内存管理 |
| 四 | 控制流 | 十 | 文件操作 |
| 五 | 函数（返回值纪律、回调函数） | 十一 | 预处理与多文件工程 |
| 六 | 数组与字符串 | 十二 | 我的易错点复盘（错题表 + 自查清单 + 报错速查） |

其中几处是踩过坑之后专门补的：

- **二（五）程序的内存分区**：代码段 / 常量区 / `.data` / `.bss` / 栈 / 堆的读写属性与生命周期，解释为什么改字符串字面量会崩。
- **五（二）返回值的纪律**：函数别用 `void` 收尾、别靠副作用带结果，入参加 `const` 保持输入不被破坏。
- **五（三）回调函数**：函数指针做参数的写法、`qsort` 实例与四个常见错误。
- **八（二）内存对齐三步法**：先找对齐值 → 逐成员排 → 整体补齐，并给出成员顺序不同导致 `sizeof` 差 4 字节的完整偏移表。
- **八（三）共用体**：大小不等于最大成员，要向上取整到对齐值（`char[5] + int` 是 8 不是 5）。
- **八（四）枚举**：枚举变量并不限制只能存定义过的值，`switch` 的 `default` 因此永远不能省。

## 浏览方式

**在线（推荐）**：开启 GitHub Pages 后访问 `https://<你的用户名>.github.io/c-language-notes/`。
开启方法：仓库 **Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / 目录选 `/docs`**，保存后等一两分钟即可。

**本地**：直接双击 `docs/index.html` 即可打开，纯静态、无外部依赖、无需联网。搜索与亮暗切换都在浏览器本地运行（`Ctrl+K` 或 `/` 唤起搜索）。

Word 版直接用 Word / WPS 打开，第十二章为预留的复盘填写区，表格单元格可编辑。

## 关于插图

正文里 10 张插图（运算符优先级总表、位运算置位/清位与掩码、浮点比较、const 参数与 const 指针、getmemory 经典题、字符串越界、内存按字节编号等）都存放在 `src/images/`，由 Markdown 中的 `![图注](images/文件名.png)` 引用。

**不要直接在 Word 里粘贴图片**：`docs/` 与 `notes/` 都是生成物，直接贴图会在下次重新生成时丢失。要加图，把图片放进 `src/images/`，再在 Markdown 里加一行引用。
