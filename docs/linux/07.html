7. 文件属性：stat 家族与 ls -li 的实现

ls -l 输出的每一列都来自 struct stat。理解这个结构体的位布局，才能真正读懂权限字符串。

（一）三个函数的分工

函数输入符号链接行为典型场景
stat路径取目标文件的属性查看链接指向的真实文件大小
lstat路径取链接自身的属性遍历目录、ls -l 显示 l 类型
fstat描述符对已打开文件操作避免 TOCTOU（检查与使用之间被替换）

（二）struct stat 关键字段

字段类型含义
st_devdev_t所在设备号
st_inoino_tinode 号，同一文件系统内唯一
st_modemode_t文件类型 + 权限，核心字段
st_nlinknlink_t硬链接数
st_uid / st_giduid_t / gid_t属主 / 属组
st_rdevdev_t设备文件的主次设备号
st_sizeoff_t文件大小（字节）；目录的大小是目录项占用
st_blksizeblksize_t最优 I/O 块大小，通常 4096
st_blocksblkcnt_t占用 512 字节块的数量
st_atimetime_t最后访问时间
st_mtimetime_t最后内容修改时间
st_ctimetime_t最后状态改变时间

重要纠正：教材把 st_ctime 注释为「创建时间」，这是错的。Linux 的 ctime 是 change time——inode 状态（权限、属主、链接数、内容）任一改变都会更新它，改名、chmod 都会刷新。真正的创建时间需要 statx() 的 STATX_BTIME 字段，且依赖文件系统支持。用 ctime 当「创建时间」会导致「改了权限，创建时间就变了」的诡异现象。

（三）st_mode 的位布局

st_mode 是 16 位，高 4 位是文件类型，低 12 位是权限（含三位特殊权限）：

文件类型取值（八进制）：

宏值字符类型
S_IFREG0100000-普通文件
S_IFDIR0040000d目录
S_IFCHR0020000c字符设备
S_IFBLK0060000b块设备
S_IFIFO0010000p命名管道
S_IFLNK0120000l符号链接
S_IFSOCK0140000s套接字

判断类型优先用宏，可读性和可移植性都更好：

权限位宏：S_IRUSR(0400)、S_IWUSR(0200)、S_IXUSR(0100)，GRP 与 OTH 依次右移 3 位、6 位。

（四）实现 ls -li

几个实现要点：

  • st_ino 是 ino_t，打印要显式转 long 或 %ju + uintmax_t，否则 64 位下有告警。
  • 时间用 localtime_r 而非 localtime，避免静态缓冲区被覆盖。
  • 权限字符串里的 x 位在 setuid/setgid/sticky 存在时应显示 s/s/t，标准 ls 用 S_ISUID 等宏处理，这是完整复刻的最后一块拼图。

（五）硬链接与符号链接

对比项硬链接符号链接
本质同一 inode 的新目录项独立文件，内容是目标路径
inode与源文件相同与源文件不同
st_nlink增加不变
跨文件系统不允许允许
链接目录不允许（普通用户）允许
源文件删除数据仍在，链接仍可用变成断链（dangling）
ls -l 显示普通文件l 类型 + -> 目标

易错点：用 stat 判断符号链接指向的是不是目录，得到的是目标的信息；要判断链接自身必须用 lstat。这是递归删除、目录遍历出错的高频原因。
