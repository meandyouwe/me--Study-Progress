# 附录 · 使用说明

## （一）这份笔记和原始 PDF 的关系

本笔记以五份课程 PDF 为骨架，做了三件事：**归并同构知识**（把 `open/opendir/fork` 归到「句柄 + 三步骤」的统一模式）、**补全边界情况**（短读短写、`EINTR`、信号丢失、`ctime` 语义纠正）、**补上工程闭环**（每章给出可独立运行的完整代码与验收标准）。

| 原始 PDF | 对应章节 | 补充了什么 |
|---|---|---|
| 3. 文件操作和时间编程 | 第 2–5 章 | Makefile 完整规则、`umask` 运算过程、短读短写循环、`localtime` 静态缓冲区陷阱、`CLOCK_MONOTONIC` 计时 |
| 4. 目录操作和文件属性 | 第 6–7 章 | 递归遍历的四个细节、`d_type` 取值、`st_ctime` 语义纠正、硬链接与符号链接对比 |
| 5. 进程 | 第 8–9 章 | COW、`wstatus` 位解析、`fork` 缓冲区复制、`exec` 六函数命名规律、`system` 的代价 |
| 6. 信号 | 第 10 章 | 62 个信号的编号真相、`sigaction` 与 `SA_RESTART`、异步信号安全、`SIGCHLD` 丢失的循环解法 |
| 7. LVGL 的介绍及其使用 | 第 11 章 | LVGL 线程安全的正确做法、移植三要素、字库体积估算、性能优化要点 |

> 说明：PDF 中 `st_ctime` 注释为「创建时间」属常见教材笔误，本笔记按 POSIX 语义纠正为「状态改变时间」（change time）。考试如遇原题，请以课程口径为准；实际开发按本笔记为准。

## （二）三种形态怎么用

| 形态 | 位置 | 适合 |
|---|---|---|
| 网页版 | `docs/index.html` | 全文搜索、随时查阅、亮暗模式 |
| Word 版 | `notes/` | 打印、写批注、长期维护复盘表 |
| Markdown 源 | `src/` | 唯一内容源，改完重新生成两端 |

**在线浏览**：仓库开启 Pages 后访问 `https://<用户名>.github.io/<仓库名>/`。开启方法：**Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / 目录选 `/docs`**，保存后等一两分钟。

**本地浏览**：直接双击 `docs/index.html`。纯静态、无外部依赖、无需联网。搜索与亮暗切换都在浏览器本地运行（`/` 或 `Ctrl+K` 唤起搜索）。

## （三）内容维护约定

1. **只改 `src/` 下的 Markdown**。`docs/` 与 `notes/` 是生成物，直接改会在下次生成时被覆盖。
2. 新增一章：在 Markdown 里加一级标题 `# N. 标题`，小节用 `## （一）标题`，重新生成即可。
3. 代码块用围栏语法并标注语言（`c`、`make`、`bash`、`text`），站点会按 C 语法高亮。
4. 表格用标准 Markdown 表格，生成时会包一层可横向滚动的容器，窄屏不挤压。
5. 第十二章的复盘表在网页上填写只存本机 `localStorage`，要长期保存请写到 Word 或 Markdown 里。

## （四）建议的学习顺序

如果时间有限，按「能在机器上跑起来」的优先级排序：

1. **第 4 章**（系统 I/O）—— 一切的基础，`open/read/write/lseek` 必须闭卷写出来。
2. **第 9 章**（进程控制）—— `fork` + `exec` + `wait` 三件套，能写 Shell 就算过关。
3. **第 10 章**（信号）—— 让程序可控，`SIGCHLD` 回收是工程必备。
4. **第 5、6、7 章**（时间、目录、属性）—— 组合起来就是 `ls`、`find`、日志系统。
5. **第 11 章**（LVGL）—— 有界面才有产品感，但它是前四步的应用，不是替代。
6. **第 2 章**（Makefile）—— 随时补，工程一大就绕不开。

## （五）自测题

能独立答出下面八题，说明这套内容真正掌握了：

1. `open("f", O_WRONLY|O_CREAT, 0666)` 在 `umask=0022` 下创建的文件权限是什么？为什么不是 `666`？
2. `read` 返回 0 与返回 -1 分别意味着什么？为什么不能用 `while(read(...))` 判断？
3. 为什么 `localtime` 连续调用两次，第一次的结果会被覆盖？多线程下怎么改？
4. `stat` 与 `lstat` 的区别是什么？遍历目录时该用哪个，为什么？
5. `st_ctime` 是创建时间吗？如果不是，Linux 上如何取真正的创建时间？
6. `fork(); fork(); fork();` 之后共有几个进程？`printf` 放在 `fork` 之前会打印几次，为什么？
7. `wait` 得到的 `status` 为 256，子进程的退出码是多少？为什么？
8. `SIGKILL` 与 `SIGSTOP` 有什么共同点？为什么内核要把它们设为不可捕获？

> 答案都能在前面对应章节里找到。找不到说明那一节需要重读——这比刷题有效。
