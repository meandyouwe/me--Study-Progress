# 12. 综合项目：MP3 播放器与复盘

前面九章是零件，这一章把零件装成机器。两个版本共用同一套控制逻辑：**无界面版**用键盘驱动，**LVGL 版**用按钮驱动，差别只在「输入源」和「输出去哪」。

## （一）需求拆解

| 功能 | 无界面版 | LVGL 版 | 依赖的技术 |
|---|---|---|---|
| 获取歌单 | `glob("*.mp3")` | 同左，结果存入数组 | 第 9 章 glob |
| 播放 | `fork` + `execlp("mpg123", ...)` | 同左，封装成函数 | 第 9 章 exec |
| 暂停 | `kill(pid, SIGSTOP)` | 按钮事件触发 | 第 10 章信号 |
| 继续 | `kill(pid, SIGCONT)` | 按钮事件触发 | 第 10 章信号 |
| 下一首 | `kill(pid, SIGKILL)` + 重新 `fork` | 同左 | 第 9、10 章 |
| 回收子进程 | `signal(SIGCHLD)` + `waitpid` 循环 | 同左 | 第 9、10 章 |
| 显示时间 | 无 | `pthread` + `lv_label_set_text` | 第 11 章、第 5 章时间 |
| 显示歌名 | `printf` | `lv_label_set_text` + 自制字库 | 第 11 章 |
| 退出清理 | `atexit` 恢复终端 | 同左 | 第 9 章 atexit |

## （二）架构：一个父进程 + 一个「可替换」的子进程

```
        ┌──────────────────────────────┐
        │  父进程（菜单 / 界面 / 状态机）  │
        │  - 维护歌单与当前索引            │
        │  - 维护 playing / paused 状态    │
        │  - 接收按键或按钮事件            │
        └───────────┬──────────────────┘
                    │ fork + exec
                    ▼
        ┌──────────────────────────────┐
        │  子进程：mpg123 song_n.mp3     │
        │  - 被 SIGSTOP / SIGCONT 控制   │
        │  - 被 SIGKILL 结束             │
        └───────────┬──────────────────┘
                    │ 退出时
                    ▼
              SIGCHLD → 父进程 waitpid 回收
```

核心设计原则：**播放器永远不阻塞父进程**。父进程只做「状态管理 + 发信号」，真正的音频解码全在子进程里。

## （三）无界面版骨架

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <signal.h>
#include <glob.h>
#include <sys/types.h>
#include <sys/wait.h>

static glob_t  g_list;
static int     g_index  = 0;
static pid_t   g_pid    = -1;
static int     g_paused = 0;

static void restore_term(void)
{
    system("stty echo");          /* mpg123 关掉了回显 */
    printf("\033[?25h");          /* 恢复光标 */
    fflush(stdout);
}

static void on_chld(int sig)
{
    int st;
    while (waitpid(-1, &st, WNOHANG) > 0) { }
}

static int play_current(void)
{
    g_pid = fork();
    if (g_pid < 0) { perror("fork"); return -1; }

    if (g_pid == 0) {
        execlp("mpg123", "mpg123", "-q", g_list.gl_pathv[g_index], NULL);
        perror("execlp");         /* exec 失败才会走到这里 */
        _exit(127);
    }
    g_paused = 0;
    return 0;
}

static void stop_current(void)
{
    if (g_pid > 0) {
        kill(g_pid, SIGKILL);
        waitpid(g_pid, NULL, 0);  /* 立即回收，避免短暂僵尸 */
        g_pid = -1;
    }
}

int main(int argc, char *argv[])
{
    const char *pattern = (argc > 1) ? argv[1] : "./*.mp3";

    if (glob(pattern, 0, NULL, &g_list) != 0 || g_list.gl_pathc == 0) {
        fprintf(stderr, "没有找到匹配的音频文件\n");
        return -1;
    }

    atexit(restore_term);
    signal(SIGCHLD, on_chld);
    printf("共 %zu 首，s=暂停 c=继续 n=下一首 l=上一首 q=退出\n",
           g_list.gl_pathc);

    play_current();

    int ch;
    while ((ch = getchar()) != EOF) {
        switch (ch) {
        case 's':
            if (g_pid > 0 && !g_paused) { kill(g_pid, SIGSTOP); g_paused = 1; }
            break;
        case 'c':
            if (g_pid > 0 && g_paused)  { kill(g_pid, SIGCONT); g_paused = 0; }
            break;
        case 'n':
            stop_current();
            g_index = (g_index + 1) % (int)g_list.gl_pathc;
            play_current();
            break;
        case 'l':
            stop_current();
            g_index = (g_index - 1 + (int)g_list.gl_pathc) % (int)g_list.gl_pathc;
            play_current();
            break;
        case 'q':
            stop_current();
            globfree(&g_list);
            return 0;
        default:
            break;
        }
        printf("正在播放：%s\n", g_list.gl_pathv[g_index]);
    }

    stop_current();
    globfree(&g_list);
    return 0;
}
```

> 易错点：`getchar()` 读到 EOF 后不 `clearerr` 就再读，会一直返回 EOF 导致死循环。交互式程序还要注意 `mpg123` 抢占终端——用 `-q` 静默，并在 `mpg123` 退出后 `stty echo`。

## （四）LVGL 版的接法

界面逻辑不变，只换输入与输出：

```c
static void on_play_pause(lv_event_t *e)
{
    if (lv_event_get_code(e) != LV_EVENT_CLICKED) return;

    if (g_paused) {
        kill(g_pid, SIGCONT);
        g_paused = 0;
        lv_imgbtn_set_state(guider_ui.screen_imgbtn_stop_or_start,
                            LV_BTN_STATE_RELEASED);
    } else {
        kill(g_pid, SIGSTOP);
        g_paused = 1;
        lv_imgbtn_set_state(guider_ui.screen_imgbtn_stop_or_start,
                            LV_BTN_STATE_CHECKED_RELEASED);
    }
}

static void on_next(lv_event_t *e)
{
    if (lv_event_get_code(e) != LV_EVENT_CLICKED) return;
    stop_current();
    g_index = (g_index + 1) % (int)g_list.gl_pathc;
    play_current();
    lv_label_set_text(guider_ui.screen_label_song,
                      g_list.gl_pathv[g_index]);
}
```

时间显示线程按第 11 章的写法创建，但**必须**用互斥锁或 `lv_async_call` 保护，否则与主线程的 `lv_timer_handler` 竞争对象树。

三个验收点（对应课程作业的「严苛测试」）：

1. 连续按「上一首/下一首」20 次，`ps -ef | grep mpg123` 只能有 1 个进程；
2. 暂停状态按「下一首」，新歌必须是播放态，不能继承暂停；
3. 退出后终端回显正常、光标可见、无残留 `mpg123`。

## （五）状态机：把边界情况穷举掉

| 当前状态 | 事件 | 动作 | 新状态 |
|---|---|---|---|
| 播放中 | 暂停 | `SIGSTOP` | 已暂停 |
| 播放中 | 下一首 | `SIGKILL` + `waitpid` + `fork` | 播放中（新歌） |
| 已暂停 | 继续 | `SIGCONT` | 播放中 |
| 已暂停 | 下一首 | `SIGKILL` + `fork` | 播放中（新歌） |
| 播放中 | 自然结束 | `SIGCHLD` 回收 | **空闲**（需决定是否自动下一首） |
| 任意 | 退出 | `SIGKILL` + `globfree` + 恢复终端 | 结束 |

「自然结束」这一格是作业里最容易漏的：不处理就会停在「没有子进程但状态还是播放中」，再按暂停会 `kill` 到一个已回收的 PID（可能命中无关进程）。

## （七）高频错误自查清单

写完一屏代码，按这张表过一遍，能拦掉大部分低级错误：

- [ ] `open` 的 `flags` 含 `O_CREAT` 时，第三个 `mode` 参数写了吗？
- [ ] `read`/`write` 的返回值用 `ssize_t` 接了吗？判断条件写成 `> 0` 而不是非零吗？
- [ ] 循环读写是否处理了「短读/短写」？
- [ ] `strlen` 与 `sizeof` 用对了吗（写字符串用前者，写结构体用后者）？
- [ ] `localtime` / `gmtime` / `readdir` 返回的静态缓冲区，是否在下次调用前就用掉了？
- [ ] `fork` 之前 `fflush` 了吗？子进程退出用 `_exit` 了吗？
- [ ] `wait` 的 `wstatus` 是否用 `WEXITSTATUS` 解析，而不是直接打印？
- [ ] 信号处理函数里只调用了异步信号安全函数吗？标志位是 `volatile sig_atomic_t` 吗？
- [ ] `exec` 的参数列表以 `NULL` 结尾了吗？`arg0` 写了吗？
- [ ] `glob` 的结果 `globfree` 了吗？
- [ ] 路径拼接用 `snprintf` 并检查返回值了吗？
- [ ] `lstat` 与 `stat` 选对了吗（遍历目录用前者）？
- [ ] 所有失败分支都 `perror` 了吗，还是只 `return -1`？
- [ ] `chdir` 之后有没有切回来，或改用完整路径？
- [ ] 多线程改 LVGL 对象时加锁 / 走 `lv_async_call` 了吗？

## （八）常见报错速查

| 报错信息 | 阶段 | 根因 | 处理 |
|---|---|---|---|
| `undefined reference to 'xxx'` | 链接 | 函数只有声明没有实现，或没链接库 | 补 `.c` / 加 `-lxxx` |
| `multiple definition of 'xxx'` | 链接 | 变量或函数在头文件里定义，被多次包含 | 头文件改 `extern`，定义收到一个 `.c` |
| `implicit declaration of function 'xxx'` | 编译 | 缺头文件 | `man 2 xxx` 查所属头文件 |
| `cannot open shared object file` | 运行 | `.so` 不在搜索路径 | `LD_LIBRARY_PATH` / `rpath` / `ldconfig` |
| `Permission denied`（open） | 运行 | 权限不足或文件属主不对 | `ls -l` 看权限，`chmod` 调整 |
| `No such file or directory`（open） | 运行 | 路径错、相对路径基准错、`chdir` 副作用 | 打印 `getcwd()` 确认 |
| `Bad file descriptor` | 运行 | 用了未打开/已关闭的 `fd` | 检查 `open` 返回值与 `close` 时机 |
| `Segmentation fault (core dumped)` | 运行 | 空指针、越界、`vfork` 子进程 `return` | `gdb ./a.out core` 看栈 |
| `Resource temporarily unavailable` | 运行 | `fork` 达上限或非阻塞 I/O 无数据 | 查进程数，处理 `EAGAIN` |
| `Interrupted system call` | 运行 | 慢系统调用被信号打断 | 用 `sigaction` + `SA_RESTART` 或重试 |
| `missing separator` | make | 命令行用了空格而非 Tab | 换 Tab |
| `relocation R_X86_64_32 ... can not be used` | 链接 | 动态库没加 `-fPIC` | 编译加 `-fPIC` |
| 终端不显示输入、光标消失 | 运行 | `mpg123` 改了终端属性 | `stty echo` + `\033[?25h` |
| 界面汉字显示成方块 | 运行 | 未把 label 字体设为中文字库 | 引入字库并 `lv_obj_set_style_text_font` |
