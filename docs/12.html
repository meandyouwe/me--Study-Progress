（二）高频错误自查清单

下表按"是否已掌握"自查，未掌握的项转入上表重点复盘。

检查项典型表现自查
数组下标越界访问 a[n]（合法范围 0~n-1）
字符串忘记 '\0'手动填字符未补结尾符，strlen 结果异常
指针未初始化即使用段错误，地址为随机值
free 后继续使用悬垂指针，偶发崩溃
switch 漏 break命中一个 case 后继续向下执行
if (a = 1) 误写赋值条件恒真，逻辑静默出错
strcmp 返回值当布尔用相等时返回 0，条件判断反了
scanf 忘记取地址符程序崩溃或数据错乱
有符号/无符号混比循环条件恒真、比较结果反直觉
宏参数未加括号展开后优先级错误，结果偏离
局部变量未初始化值不确定，不同环境表现不同
文件未判空即读fopen 返回 NULL 后崩溃
函数只算不返回全写成 void、结果靠出参或全局变量带出，调用方拿不到值
非 void 函数漏 return有分支没返回值，行为不确定，告警被忽略
入参被函数改掉没加 const，函数内就地把实参数组改写了
回调多写了括号qsort(a, n, 4, cmp(a, b)) 传的是 int 不是函数指针
写字符串字面量char *s = "abc"; s[0] = 'x'; 运行期崩溃
结构体成员顺序随手排同样字段换顺序，sizeof 差 4~8 字节
union 大小按最大成员算忘了向上取整到对齐值，缓冲区开小、写越界
枚举变量存了定义外的值未校验就当下标或 switch 分支

（三）常见报错速查

报错信息常见原因排查方向
expected ';' before ...上一行漏分号、括号不配对看报错行的前一行
undefined reference to 'xxx'只声明未定义，或未链接对应目标文件/库查定义位置、编译命令
implicit declaration of function未包含头文件或未写原型补 #include
segmentation fault空指针/野指针解引用、数组越界、栈溢出打印指针值与下标
stray '\357' in program混入中文全角符号（如全角分号、括号）检查标点是否为半角
warning: comparison between signed and unsigned有符号与无符号混比统一类型或加显式转换
warning: control reaches end of non-void function非 void 函数有分支没 return补齐 return，或把返回类型改成 void
passing argument from incompatible pointer type回调函数签名不匹配、或传了函数调用的结果对齐参数表与返回类型，只传函数名
warning: assignment discards 'const' qualifier把 const 指针赋给普通指针保持 const 链完整，别强转绕开
sizeof 结果比预期大 / 结构体读错位结构体对齐或 union 大小算错用 offsetof 验偏移，逐字段核对
