Linux 系统编程与 LVGL 知识总结

description
按课程顺序整理的 Linux 系统编程知识主干：文件 I/O、时间、目录与属性、进程、信号，以及 LVGL 图形界面。

本书以五份课程讲义为骨架，按「工程组织 → 文件 I/O → 时间与文件系统 → 进程与信号 → 图形界面」的顺序组织。每章保留可复用的判断规则、完整示例代码与常见错误对照表，第十二章给出综合项目拆解和可在线填写的复盘区。
