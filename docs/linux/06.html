6. 目录操作

目录在 Linux 里也是文件，只是内容特殊：它存放的是「文件名 → inode 号」的映射表。因此目录操作不能被 read 直接读，必须用 opendir / readdir 这一组封装。

（二）struct dirent 的字段

  • d_name 只有文件名，不含路径。要拿属性必须自己拼完整路径。
  • d_type 常见值：DT_REG（普通文件）、DT_DIR（目录）、DT_LNK（符号链接）、DT_FIFO、DT_SOCK、DT_CHR、DT_BLK、DT_UNKNOWN。
  • 每次 readdir 返回的是指向 DIR 内部静态缓冲区的指针，下一次调用会覆盖它。需要保存必须 strcpy 出来。

（三）目录自身的增删改查

函数原型说明
mkdirint mkdir(const char *path, mode_t mode)创建目录，权限受 umask 影响
rmdirint rmdir(const char *path)只能删空目录
chdirint chdir(const char *path)切换当前工作目录

易错点：chdir 改的是进程级的当前目录，会影响之后所有相对路径。遍历目录时如果 chdir 进去却没有 chdir 回来，后续 open("./x") 会指向错误位置。稳妥做法是不 chdir，全程用 snprintf 拼绝对/相对完整路径。

（四）递归遍历的正确写法

四个必须处理的细节：

  1. 过滤 . 与 ..，否则无限递归。
  2. 用 lstat 而非 stat，否则符号链接指向目录时会绕进去，可能形成环。
  3. 路径拼接用 snprintf 且检查返回值，strcat 溢出是遍历程序的头号崩溃原因。
  4. PATH_MAX 在 Linux 通常是 4096，但深层嵌套仍可能超限，工程上要判断 snprintf 返回值是否 >= sizeof(full)。

扩展 · 标准库已有成熟实现：nftw(path, fn, 16, FTW_PHYS) 一行完成递归遍历，FTW_PHYS 表示不跟随符号链接。手写递归用于教学和理解，生产代码优先考虑 nftw 或 fts_open。
