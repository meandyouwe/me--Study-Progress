12. 综合项目：MP3 播放器与复盘

前面九章是零件，这一章把零件装成机器。两个版本共用同一套控制逻辑：无界面版用键盘驱动，LVGL 版用按钮驱动，差别只在「输入源」和「输出去哪」。

（一）需求拆解

功能无界面版LVGL 版依赖的技术

（二）架构：一个父进程 + 一个「可替换」的子进程

核心设计原则：播放器永远不阻塞父进程。父进程只做「状态管理 + 发信号」，真正的音频解码全在子进程里。

（三）无界面版骨架

易错点：getchar() 读到 EOF 后不 clearerr 就再读，会一直返回 EOF 导致死循环。交互式程序还要注意 mpg123 抢占终端——用 -q 静默，并在 mpg123 退出后 stty echo。

三个验收点（对应课程作业的「严苛测试」）：

  1. 连续按「上一首/下一首」20 次，ps -ef | grep mpg123 只能有 1 个进程；
  2. 暂停状态按「下一首」，新歌必须是播放态，不能继承暂停；
  3. 退出后终端回显正常、光标可见、无残留 mpg123。

（五）状态机：把边界情况穷举掉

当前状态事件动作新状态
播放中暂停SIGSTOP已暂停
播放中下一首SIGKILL + waitpid + fork播放中（新歌）
已暂停继续SIGCONT播放中
已暂停下一首SIGKILL + fork播放中（新歌）
播放中自然结束SIGCHLD 回收空闲（需决定是否自动下一首）
任意退出SIGKILL + globfree + 恢复终端结束

「自然结束」这一格是作业里最容易漏的：不处理就会停在「没有子进程但状态还是播放中」，再按暂停会 kill 到一个已回收的 PID（可能命中无关进程）。

（七）高频错误自查清单

写完一屏代码，按这张表过一遍，能拦掉大部分低级错误：

  • ☐ open 的 flags 含 O_CREAT 时，第三个 mode 参数写了吗？
  • ☐ read/write 的返回值用 ssize_t 接了吗？判断条件写成 > 0 而不是非零吗？
  • ☐ 循环读写是否处理了「短读/短写」？
  • ☐ strlen 与 sizeof 用对了吗（写字符串用前者，写结构体用后者）？
  • ☐ localtime / gmtime / readdir 返回的静态缓冲区，是否在下次调用前就用掉了？
  • ☐ fork 之前 fflush 了吗？子进程退出用 _exit 了吗？
  • ☐ wait 的 wstatus 是否用 WEXITSTATUS 解析，而不是直接打印？
  • ☐ 信号处理函数里只调用了异步信号安全函数吗？标志位是 volatile sig_atomic_t 吗？
  • ☐ exec 的参数列表以 NULL 结尾了吗？arg0 写了吗？
  • ☐ glob 的结果 globfree 了吗？
  • ☐ 路径拼接用 snprintf 并检查返回值了吗？
  • ☐ lstat 与 stat 选对了吗（遍历目录用前者）？
  • ☐ 所有失败分支都 perror 了吗，还是只 return -1？
  • ☐ chdir 之后有没有切回来，或改用完整路径？
  • ☐ 多线程改 LVGL 对象时加锁 / 走 lv_async_call 了吗？

（八）常见报错速查

报错信息阶段根因处理
undefined reference to 'xxx'链接函数只有声明没有实现，或没链接库补 .c / 加 -lxxx
multiple definition of 'xxx'链接变量或函数在头文件里定义，被多次包含头文件改 extern，定义收到一个 .c
implicit declaration of function 'xxx'编译缺头文件man 2 xxx 查所属头文件
cannot open shared object file运行.so 不在搜索路径LD_LIBRARY_PATH / rpath / ldconfig
Permission denied（open）运行权限不足或文件属主不对ls -l 看权限，chmod 调整
No such file or directory（open）运行路径错、相对路径基准错、chdir 副作用打印 getcwd() 确认
Bad file descriptor运行用了未打开/已关闭的 fd检查 open 返回值与 close 时机
Segmentation fault (core dumped)运行空指针、越界、vfork 子进程 returngdb ./a.out core 看栈
Resource temporarily unavailable运行fork 达上限或非阻塞 I/O 无数据查进程数，处理 EAGAIN
Interrupted system call运行慢系统调用被信号打断用 sigaction + SA_RESTART 或重试
missing separatormake命令行用了空格而非 Tab换 Tab
relocation R_X86_64_32 ... can not be used链接动态库没加 -fPIC编译加 -fPIC
终端不显示输入、光标消失运行mpg123 改了终端属性stty echo + \033[?25h
界面汉字显示成方块运行未把 label 字体设为中文字库引入字库并 lv_obj_set_style_text_font
